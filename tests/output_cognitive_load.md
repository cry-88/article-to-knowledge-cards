# Cognitive Load Theory 知识卡片

> 原文为英文，已译为中文卡片便于复习。共提炼出 8 个独立知识点（在 5–8 张范围内，无硬凑、无编造）。

## 卡片 1：CLT 的基本前提——有限的工记 vs 无限的长记
**核心知识**：人类工作记忆在容量和持续时间上都有严格限制，而长时记忆几乎无限；当任务总负荷超过工作记忆可用资源时，学习就会失败。
**简明解释**：认知负荷理论（John Sweller 于 1988 年提出）把学习失败归因于"心理负荷超载"。它建立在对人类认知架构的理解之上：工作记忆狭窄且短暂，长时记忆容量则近乎无限。
**例子 / 自测**：为什么一口气塞给你 10 个互不相关的概念，你往往记不住？请用工作记忆的局限性解释。

## 卡片 2：认知负荷的三分法（彼此独立且可相加）
**核心知识**：CLT 把认知负荷分为三类彼此独立且可相加的负荷：内在负荷、外在负荷、关联负荷。
**简明解释**：文章明确指出这三类是 "distinct, additive" 的，即总负荷等于三者之和。理解这一框架，是分析任何学习材料负荷的前提。
**例子 / 自测**：若某任务内在负荷高、外在负荷也高，总负荷会怎样？为什么必须同时优化两者才有意义？

## 卡片 3：内在认知负荷（Intrinsic）
**核心知识**：内在负荷来自学习材料本身的固有复杂度，由"元素交互性"决定，无法消除、只能管理。
**简明解释**：元素交互性高，意味着多个概念必须一起处理才有意义（如求微积分导数）；交互性低，则如记忆孤立的单词。内在负荷不能消除，但可通过把复杂内容切成更小的顺序单元来减轻。
**例子 / 自测**：为什么"先分步、后综合"比直接抛出完整推导更利于初学者？它针对的是哪一类负荷？

## 卡片 4：外在认知负荷（Extraneous）
**核心知识**：外在负荷来自糟糕的呈现与教学设计，与内容无关，是可有可无、应当最小化的负荷。
**简明解释**：混乱版式、文字与图示冗余叠加、记号不一致、被迫跨页查找关联信息等都会制造外在负荷。典型是"注意力分散效应"：图示与说明文字分离，迫使学习者在两处之间来回切换注意力。
**例子 / 自测**：把图表和对应的解释文字放在同一页，与分在两页相比，哪种更易学？为什么？

## 卡片 5：关联认知负荷（Germane）
**核心知识**：关联负荷是" desirable（值得追求的）"负荷，指投入于在长时记忆中建构、自动化、精炼图式的心智努力。
**简明解释**：图式是把许多离散元素打包成一个可用单元的心理结构。对专家而言，一个公式或熟悉图示算"一个图式"，而非几十条孤立事实。关联负荷支撑持久学习，应在内在与外在负荷受控后再去鼓励。
**例子 / 自测**：为什么熟练程序员看一段代码像看"一个整体"而非逐行字符？这反映了哪类负荷的作用？

## 卡片 6：专家反转效应（Expertise Reversal Effect）
**核心知识**：帮助新手的策略可能阻碍高阶学习者——例题（worked examples）对初学者降低外在负荷，对专家却冗余而浪费。
**简明解释**：这是 CLT 衍生的核心设计原则：教学策略的效果会随学习者专长水平而反转。专家更擅长从无引导的练习题中学习，而例题对他们已是多余。
**例子 / 自测**：给已熟练掌握语法的学生继续大量"例题＋逐步讲解"，可能带来什么反效果？

## 卡片 7：CLT 的边界——它不是动机或注意力理论
**核心知识**：CLT 只预测与"工作记忆限制"相关的结果，并非关于动机或注意力的通用理论。
**简明解释**：低认知负荷的课也可能因学生缺乏兴趣或动机而失败。把"认知超载"误认为"不参与／走神"，是运用该理论的教育者常犯的错误。
**例子 / 自测**：一个负荷很低却极其无聊的讲解，为何仍可能无效？这说明 CLT 管不到哪一类因素？

## 卡片 8：协作认知负荷（Collaborative Cognitive Load）
**核心知识**：小组学习可把工作记忆资源分布到成员之间，但协调开销可能引入新的外在负荷，因此协作未必自动减负。
**简明解释**：这是 CLT 的现代扩展：群体学习能"分摊"认知资源，但成员间的沟通与协调成本会新增外在负荷，所以小组合作并不自动降低总体认知负担。
**例子 / 自测**：为什么"四人小组"有时反而比"各自独立"更累？请用协作负荷的思路解释。
