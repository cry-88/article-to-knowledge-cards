# make-knowledge-cards

把文章或本地 Markdown / TXT 文件整理成 5～8 张知识卡片的开源 Skill。

## 项目解决什么问题

读长文、读资料时，我们常陷入两个困境：一是信息太多、抓不住重点；二是读完就忘，难以高效复习。
`make-knowledge-cards` 解决这个问题——它把一篇文章「拆碎」成一组**小而独立、便于复习与记忆**的知识卡片，
帮你只留下真正重要的知识点，而不是又生成一篇冗长的摘要。

它刻意保持「轻」：纯指令驱动、不依赖任何脚本，也不替你编造内容或硬凑数量。

## 主要功能

- **提取重点**：从文章或文件中提炼真正重要的、独立的知识点，过滤掉重复、废话与铺垫。
- **一卡一点**：每张卡片只讲一个知识点，结构固定为四部分——标题、核心知识、简明解释、例子或自测。
- **去重**：把换个说法重复出现的同一观点合并为一张卡片。
- **不编造**：所有内容都可在原文中找到依据；原文缺例子时改用自测题，绝不虚构事实、数据或例子。
- **不硬凑**：原文知识点不足 5 个时，只生成能支撑的张数并附一句话说明，绝不为了凑数灌水。
- **两种输入**：支持直接粘贴文章，也支持给出本地 `.md` / `.txt` 文件路径。
- **语言跟随原文**：中文文章生成中文卡片，英文文章生成英文卡片。

> 暂不支持：网页抓取、PDF、Anki 导出、图形界面。

## 安装方法

本仓库是一个符合开源 Agent Skills 规范的 Skill，核心只有两个文件：`SKILL.md` 与 `agents/openai.yaml`，无需安装任何依赖或脚本。

### 方式一：用于 WorkBuddy

把整个 `skills/make-knowledge-cards/` 文件夹复制到你的 Skills 目录之一：

- **用户级（对所有项目生效）**：`~/.workbuddy/skills/make-knowledge-cards/`
- **项目级（仅当前项目生效）**：`<你的项目>/.workbuddy/skills/make-knowledge-cards/`

复制后重启/刷新对话即可在对话中触发。

### 方式二：用于 OpenAI Agents SDK / Codex

将其放入你的 skills 目录（如 `skills/` 目录）下，保持 `make-knowledge-cards/` 这一级目录名不变即可。
`agents/openai.yaml` 是 OpenAI Agents / Codex 的界面元数据，其他平台会忽略它，不影响使用。

## 使用方法

### 1. 直接粘贴文章

把文章贴在对话里，并说明要生成卡片即可，例如：

> 帮我把下面这篇文章做成知识卡片：
> （粘贴文章内容）

### 2. 提供本地文件路径

给出 `.md` 或 `.txt` 文件的完整路径，例如：

> 把 `/path/to/your/file.md` 做成知识卡片

Skill 会先读取文件，再生成卡片。

### 3. 暂不支持的请求

- **网页链接抓取** → 请把网页内容复制出来再粘贴
- **PDF** → 先转为 `.md` / `.txt` 文本再提交
- **Anki 导入文件**（`.apkg` / `.csv`）→ 本 Skill 只输出 Markdown 卡片
- **图形界面** → 仅通过对话与文本文件交互

## 输入输出示例

**输入（粘贴的片段）：**

```
缓存用于加速数据访问。最常见的两种是本地缓存和分布式缓存。
本地缓存速度快但容量有限；分布式缓存可横向扩展，但存在一致性问题。
```

**输出：**

```markdown
## 卡片 1：缓存的作用
**核心知识**：缓存通过暂存高频访问的数据来加速读取、降低后端压力。
**简明解释**：当相同数据被反复请求时，直接从更快的存储层返回结果，
可显著减少数据库或远程调用的开销。
**例子 / 自测**：什么场景下引入缓存收益最大？回想你见过的"热点数据反复查询"的例子。

## 卡片 2：本地缓存 vs 分布式缓存
**核心知识**：本地缓存低延迟但容量受限，分布式缓存可扩展但带来一致性挑战。
**简明解释**：本地缓存驻留在进程内，访问最快却有内存上限；分布式缓存跨节点共享、
可水平扩容，但多副本间的数据同步会产生一致性问题。
**例子 / 自测**：若某数据要求强一致，你会优先选哪种缓存？为什么？
```

当原文知识点少于 5 个时，会生成更少的卡片并附一句话说明，例如：

```markdown
## 卡片 1：番茄工作法的基本节奏
**核心知识**：番茄工作法把工作切成 25 分钟一段，每段之间休息 5 分钟。
**简明解释**：它是一种时间管理方法，用固定长度的专注时段搭配短休息来维持专注、减少拖延。
**例子 / 自测**：连续 4 个番茄钟大致会经历多长的专注与休息安排？

> 说明：原文仅包含 1 个明确知识点，故生成 1 张卡片，未强行凑数。
```

## 项目结构

```
skills/make-knowledge-cards/
├── SKILL.md          # Skill 指令（核心，含输入处理/卡片格式/质量规则/不支持项）
└── agents/
    └── openai.yaml   # OpenAI Agents / Codex 界面元数据（display_name + short_description）
```

## 校验

使用官方校验脚本（路径以你本地的 skill-creator 为准）：

```bash
python skills/.system/skill-creator/scripts/quick_validate.py skills/make-knowledge-cards
```

输出 `Skill is valid!` 即通过。
